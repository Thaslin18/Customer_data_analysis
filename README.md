# Customer Data Analysis & Segmentation

## Overview
Practice project analyzing synthetic customer data: data cleaning, exploratory analysis, customer behavior, and simple customer segments. Dataset is synthetic and not real customer data.

## Dataset
`data/customer_data.csv` contains 803 rows (800 generated customers + 3 duplicate rows) and fields: Customer_ID, Age, Gender, Annual_Income, Total_Spend, Store_Visits, Orders, Days_Since_Last_Purchase, Loyalty_Tier, Region, Online_Shopping.

## Tools
Python, Pandas, NumPy, Matplotlib, Jupyter Notebook, SQL.

## Workflow
1. Inspect data, missing values and duplicates
2. Remove duplicates and fill missing values
3. Explore spending, order activity, regions and loyalty tiers
4. Create simple segments using spending and orders
5. Generate summary CSVs and charts

## Run
Install: `pip install -r requirements.txt`
Run script: `python src/customer_analysis.py`
Or open `notebooks/customer_analysis.ipynb` in Jupyter / VS Code.
